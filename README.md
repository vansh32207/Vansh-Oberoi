# 100 Days of Code — C Programming

This repository contains my solutions for the **100 Days of Code Daily Challenge** at UPES.
- **Challenge Website**: [https://maitysoumik.github.io/basic-coding-with-c/](https://maitysoumik.github.io/basic-coding-with-c/)
- **Author**: [Vansh Oberoi](https://github.com/vansh32207)
- **Schedule**: Two problems a day for the first 50 days, one problem a day after that (100 Days, 150 Problems).
